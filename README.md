# AVL-Visualizer
🌳 AVL.Visualizer — Interactive AVL Tree Dashboard

A modern, interactive AVL Tree Visualizer built using HTML, CSS, and JavaScript.
This project provides a clean dashboard-style UI to insert nodes and visualize AVL tree balancing in real time.

🚀 Features

🔁 Automatic AVL Balancing

Supports LL, RR, LR, RL rotations

🎨 Modern Dark UI

Gradient nodes, glowing effects, and sidebar dashboard

📊 Real-Time Tree Visualization

Canvas-based rendering

➕ Insert Nodes Dynamically

♻️ Clear / Reset Tree

📱 Responsive Layout

Adjusts automatically on window resize

🧠 What is an AVL Tree?

An AVL Tree is a self-balancing Binary Search Tree where:
The height difference between left and right subtrees is at most 1
Rotations are used to maintain balance after insertions
This visualizer helps you see rotations and height balancing visually, making it ideal for:

Data Structures learning

Teaching demonstrations

Interview preparation
